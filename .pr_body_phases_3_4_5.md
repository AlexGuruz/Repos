## Summary

This PR bundles **Phase 3** (Growflow canonical runners), **Phase 4** (automated script/tool inventory), and **Phase 5** (prepared-context selection hardening). It improves classification, drift visibility, and chat routing quality without new assistant roles, without weakening approval gates, and without customer-alert or file-organizer scope.

---

### Phase 3 — Growflow canonical runners

- **Inventory:** `ai-lab/state/integration_inventory/growflow_runners.json` (regenerate with `python scripts/generate_growflow_runners.py` from `ai-lab`).
- **Classifier:** `ai-lab/brain/integration_inventory/growflow_classify.py` — categories, `approval_required_for_tool_registry`, prepared-context feeder flags, counts; no scripts left in `unknown_needs_review` (package `__init__` classified as `manual_diagnostic`).
- **Docs / tests:** `ai-lab/docs/GROWFLOW_CANONICAL_RUNNERS.md`, `ai-lab/tests/test_growflow_canonical_runners.py`.

---

### Phase 4 — Automated script/tool inventory

- **Generator:** `ai-lab/brain/integration_inventory/integration_inventory_generator.py`, CLI `ai-lab/scripts/generate_integration_inventory.py`.
- **Outputs:** `ai-lab/state/integration_inventory/{scripts,tools,triggers,orphans,summary}.json` + `ai-lab/docs/SCRIPT_TOOL_INVENTORY_AUTO.md`.
- **Docs / tests:** `ai-lab/docs/SCRIPT_TOOL_INVENTORY.md` (see-also), `ai-lab/tests/test_integration_inventory_generator.py`.
- **Intent:** Visibility and drift detection only — no auto tool registration, no deletions.

---

### Phase 5 — Prepared context selection hardening

- **Selector:** `ai-lab/brain/prepared_context/selection.py` — deterministic hybrid keyword + intent scoring, negative guardrails, broad lab trio vs doc/repo pairing.
- **Loader / orchestrator:** `ai-lab/brain/prepared_context/loader.py` uses the selector; `ai-lab/brain/orchestrator/main.py` adds trace fields and tries **prepared `worker_snapshot` before live worker probes** for `worker_health`.
- **Docs / tests:** `ai-lab/docs/PREPARED_CONTEXT_SELECTION_HARDENING.md`, updates to `AI_ROUTING_POLICY.md` / `AI_RESPONSE_BENCHMARKS.md`, extended prompts in `scripts/benchmark_ai_response.py`, `ai-lab/tests/test_prepared_context_selection.py`.
- **Quality gate / stale behavior:** Preserved in the loader.

---

### How to test

```bash
cd ai-lab
python -m pytest tests/test_growflow_canonical_runners.py tests/test_integration_inventory_generator.py tests/test_prepared_context_selection.py tests/test_prepared_context.py -q
```

Regenerate inventories when trees change:

```bash
python scripts/generate_growflow_runners.py
python scripts/generate_integration_inventory.py
```

Optional: `python scripts/benchmark_ai_response.py` to refresh benchmark tables.
