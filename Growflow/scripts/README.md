# Growflow Scripts

Automation and sync scripts for GrowFlow integration.

## Recovered Requirements

- **NUGZ EXPENSES col 10:** Post Grow Flow subscription expense
- **Sales export:** Export OrderItems/sales CSV for cog-allocation-system (→ csv_dump or Drive)
- **GrowFlow API:** If available, pull inventory/sales data

## Repo root utilities

- **`allocate_stock_pool_by_brand.py`** — `findOrderItems` trailing gross sales by `Product.Brand`, proportional pool split (see `company_bi/DESIGN.md`, `company_bi/METRICS.md`). Run **`python -m pytest tests/test_allocate_stock_pool.py -v`** to validate chunk boundaries (no double-counted days), dedupe, and exact pool rounding without calling the API.
- **`run_stock_pool_allocation.ps1`** — Launches the allocator from **normal Windows PowerShell**. From repo root: `.\scripts\run_stock_pool_allocation.ps1`
- **`run_sales_today.ps1`** — OAuth + Retail GraphQL for **today’s sales** (UTC); uses `config/config.yaml` `growflow.org_id` and `E:/secrets/gcp/growflowapi.txt` (or env). From repo root: `.\scripts\run_sales_today.ps1`
- **Register close → Taxes sheet:** `PYTHONPATH=. python scripts/register_close_taxes_sheet.py --export-for-date 2026-06-01` — on Register 1 close, writes MJ / Sales / Total tax to column C on the **Taxes** tab (dates in column A). Poll: `.\scripts\run_register_close_watch.ps1`. Config: `taxes_sheet` + `register_close_notify` in `config/config.yaml`.
- **Balance and Misc snapshots:** `PYTHONPATH=. python scripts/snapshot_balance_misc_sheet.py` — duplicates the **Balance and Misc** tab in the workbook (timestamped `SNAP Balance and Misc …` tabs, keeps last **28**) and writes local JSON under `data/balance_misc_snapshots/`. After each snapshot, `diff_balance_misc_snapshots.py` logs cell changes to `logs/balance_misc_changes/` (daily files + `balance_misc_changes_latest.log`). Stashbox SA (`config/config.yaml` → `balance_misc_snapshot`). **Runs on power-1** every **hour** (`GrowflowBalanceMiscSnapshot`); deploy/update: `.\scripts\deploy_balance_misc_snapshot_to_power1.ps1`.
- **Category x brand projection (markdown):** `PYTHONPATH=. python scripts/build_projection_by_category_brand.py` — writes `data/projection_by_category_brand.md` (**$18k** default pool) by **store-local** days (default **365**). **Main layout:** `Brand → categories → breakdown`; roll-up, appendix, top brands, **2-week slices** (`--biweek-*`). **Scenario / flags:** `docs/GROWFLOW_PLANNER_SCENARIO_CONTROLS.md`. **`--compare-modes`** → `*_allocation_compare.md` (buy-plan vs throughput vs gross-share, internal evaluation). `--max-brands-subprojection` caps brands in the main section. **Default excludes** `(no brand)`, `Puffin Pure`, `710 Empire`, and consignment vendors **Doc Furgsen** / **Doc Ferguson**, **Deadhead Farms**, **Arctic Extracts**, **Rooted Right Farms**. **Default `--pool-top-n` is 15** for **throughput** mode; **`--pool-top-n 0`** with **gross-share** = proportional across all cells. `--chunk-retries` for flaky API.
- **Merit pool (repo root):** `python allocate_brand_pool_merit.py` — splits a pool (default **$18k**) by **margin + 14d velocity + turnover vs inventory** (defaults **0.32 / 0.48 / 0.20** favoring fast movers + ROI). **Full year:** `--days 365 --chunk-days 30`. **Formats only** (edibles, cartridges, disposables, prerolls/infused prerolls, topicals): `--format-product-pool` (matches `ProductCategory.Name` with OR substrings; override with `--category-substrings edible,cartridge,...`). **Day-by-day brand tracker** (see if back-stock had a full velocity-window streak): `--daily-sales-csv data/brand_daily.csv` (writes `brand_daily_coverage.csv` next to it unless `--daily-coverage-csv` set). Window length: `--daily-track-days` (default = `--velocity-days`, usually 14). See `lib/brand_merit_pool.py`, `lib/brand_daily_sales.py`.
- **`lib/growflow_graphql.py`**, **`lib/growflow_queries.py`** — GraphQL client + shared queries (`findOrderItems`, `findPackages`).
- **Schema map / introspection:** `PYTHONPATH=. python scripts/introspect_growflow_schema.py --write-docs` — writes `docs/GROWFLOW_RETAIL_SCHEMA_MAP.md` and `data/growflow_schema_introspection.json`. Production Retail often **blocks** `__schema` introspection; the script then emits a **fallback** map with exact repo queries + playground discovery templates. Use `GROWFLOW_GRAPHQL_URL` for the integrations playground when available.
- **Doc index (source-of-truth workflow):** `docs/GROWFLOW_API.md` — links schema map, planner mapping, partner data checklist (`docs/GROWFLOW_NEXT_DATA_REQUEST.md`), and discovery queries.
- **Cartel infused multipack on transfers / order lines:** `docs/GROWFLOW_CARTEL_TRANSFER_IDENTIFIERS.md` — **Cartel Oil Co** + **Infused Pre-Roll Bundle** + **8.4G** as the canonical identifier; implementation in `lib/cartel_7pk_names.py`. Transfer sell-through audit: `PYTHONPATH=. python scripts/transfer_sellout_by_brand_category.py`.
- **Transfer receipt timestamps (inventory cohort vs sell-through vs bills):** `PYTHONPATH=. python scripts/export_transfer_receipt_units.py` — writes **`data/transfer_receipt_units.jsonl`** (JSONL, gitignored): each package line on **Accepted** transfers with **`received_at`**, **`received_at_epoch_ms`**, **`received_date_local`** (store TZ from config / `GROWFLOW_SALES_TZ`), **`product_object_id`**, **`cost_cents`**, **`original_qty`**. **`--skip-transfers K`** skips the **K** newest transfers (e.g. **`--skip-transfers 8`** after you already captured the latest eight); **`--append`** appends to **`--out`** instead of overwriting. For sell-through of a specific receipt, use **`transfer_cohort_sellthrough.py`** (`OrderItem.Package.objectId` ↔ transfer package line). Product-level joins use **`findOrderItems`** (`SoldAt`, `Product.objectId`); align cash timing in **Project-Kylo** / `company_bi` using **`received_date_local`** or UTC day buckets (see `lib/transfer_receipt_export.py`).
- **Transfer cohort sell-through (package-attributed):** `PYTHONPATH=. python scripts/transfer_cohort_sellthrough.py --transfer-id <id>` — counts sales where **`OrderItem.Package.objectId`** matches a package on the transfer (not `OriginId`, not `OriginalQty - CurrentQty` on transfer rows). **`--supplier`** + **`--since-received`** pick the latest matching receipt; **`--from-local`** / **`--through-local`** bound the sales window (default from receipt through today). **`--detail`** / **`--csv-out`** for per-line output. Shared queries: **`lib/growflow_queries.fetch_order_items`** (includes **`Package { objectId }`** with Brand/Package fallbacks).
- **Transfer receipts local DB (staging for dashboard analysis):** `PYTHONPATH=. python scripts/build_transfer_receipts_db.py --since 2026-04-09T00:00:00Z` — pages **Accepted** `findTransfers` from Growflow and loads **`data/transfer_receipts.db`** (SQLite, gitignored) with **`transfer_receipts`** + **`transfer_receipt_packages`** + **`transfer_receipt_sales_staging`** (one row per package line: **`product_object_id`**, **`received_day_local`** / **`received_day_utc`**, **`days_since_receipt_at_load`** snapshot at ingest, **`received_at_epoch_ms`**). After each ingest it rebuilds **`product_landed_cost_current`** (latest receipt per `Product.objectId`, so new transfers refresh landed unit cost); see **`lib/product_landed_cost_sqlite.py`**. **`--rebuild-costs-only`** refreshes that table from existing package rows without calling the API. **`--export-product-costs-csv PATH`** writes the current-cost table to CSV. Prints supplier leaderboard (`from_name`, transfer count, units, landed cost). Use **`transfer_receipt_sales_staging`** to join **`findOrderItems`** on `Product.objectId` with `SoldAt >= received_at` for post-receipt sell-through vs COG allocation dashboards.
- **MJ brand ranking → Sheet (profit/day + units/day):** `PYTHONPATH=. python scripts/rank_mj_brands_profit_velocity_sheet.py` — trailing store-local window (default **7d**), rank = normalized margin $/day + normalized units/day; writes **Brand | Supplier** to **D:E** on the same spreadsheet defaults as the supplier export. Schedule daily via Task Scheduler if desired.
- **Top 15 MJ brands per 30d windows (saved for evaluation):** `PYTHONPATH=. python scripts/export_top15_mj_brands_30d_windows.py` — default **365** store-local days in **ceil(365/30)=13** windows; ranks by **gross $** (then lines); writes timestamped **`.json`** + **`.csv`** under `exports/`. Retries on transient **520/502/503/504**; use `--chunk-days 14` if the API is flaky. **Curated ranking:** `--evaluation-filters` drops **prepackaged flower**, **bulk flower**, **710 Empire**, and **accessory / merch / gift-card style** lines (see script `filters` in JSON); granular flags: `--exclude-prepackaged-flower`, `--exclude-bulk-flower`, `--exclude-non-cannabis-accessories`, `--exclude-brands "A,B"`.
- **Discovery query harness:** `PYTHONPATH=. python scripts/run_growflow_discovery_queries.py` — POSTs `scripts/growflow_discovery_queries/discover_*.graphql` for quick validation when SDL or integrations access exists. Planner mapping: `docs/GROWFLOW_PLANNER_DATA_MAPPING.md`.
- **Projection dashboard (Sheets):** `PYTHONPATH=. python scripts/build_projection_dashboard_google_sheet.py` — pushes CSV to the capital dashboard (default **values-only**, preserves charts/formatting). **Layout reset (destructive):** requires **both** `--full-refresh` and `--confirm-layout-reset`. **Env:** copy `config/dashboard_sheets.env.example` → `config/dashboard_sheets.env` and set `STASHBOX_SERVICE_ACCOUNT` (or rely on `E:/secrets/gcp/sa.json`). **Layout baseline:** `PYTHONPATH=. python scripts/export_projection_dashboard_layout.py --print` → `exports/projection_dashboard_layout_snapshot.json`, or `.\scripts\run_export_dashboard_layout.ps1` from repo root.
